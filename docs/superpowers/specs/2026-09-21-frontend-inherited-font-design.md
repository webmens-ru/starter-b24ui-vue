# Наследование шрифта во Vue-фронтенде

## Цель

Весь Vue-фронтенд должен использовать семейство шрифта окружающей страницы. Нативные элементы управления не должны переключаться на браузерный шрифт, а компоненты с собственными размерами, насыщенностью и межстрочным интервалом должны сохранить эти настройки.

## Решение

В глобальном `src/assets/main.css`, после импортов Tailwind CSS и B24UI, корневому `#app` задаётся `font-family: inherit`.

Для `button`, `input`, `select` и `textarea` внутри `#app` задаётся `font: inherit`. Это нормализует нативные контролы, которые браузер может оформлять отдельно. Ссылки и обычные текстовые элементы наследуют шрифт от `#app` естественным образом.

Универсальное правило для каждого элемента не используется: оно способно перезаписать типографику компонентов и сломать иконочные шрифты.

## Проверка

- Автоматический тест проверяет наличие глобального правила и список нормализуемых контролов.
- Выполняются frontend-тесты, TypeScript-проверка и production-сборка.
- На тестовом стенде визуально проверяется меню товарной позиции, включая пункт «Сформировать PDF».
